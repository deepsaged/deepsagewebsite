Deepsage Launcher

All DeepSage games and books in one desktop app. Browse everything we have announced, get notified when a game is ready, and install it with one click.

Checking the latest version…

  • Updates itself. The launcher checks for a new version in the background and installs it when you click Update - and your games get updates the same way.
  • Starts with your computer. It opens quietly in your system tray when you log in, so new releases reach you without you doing anything. Closing the window keeps it in the tray. You can turn both off in Settings.
  • Checks your hardware. Before you download a game it tells you whether your PC runs it well, on low settings, or not at all.
  • Uses your DeepSage account. Sign in with the same email or Google account as on this site; your wishlist is shared.

Download

Linux

64-bit (x86_64). Needs a desktop with a system tray.

AppImage - any distro

Make it executable and run it: chmod +x deepsage-launcher_linux_x86_64.AppImage && ./deepsage-launcher_linux_x86_64.AppImage

.deb - Ubuntu, Debian, Mint

Install with sudo apt install ./deepsage-launcher_linux_amd64.deb. Auto-update works for the AppImage; with the .deb, install new versions the same way.

Windows

Windows 10 and 11, 64-bit. Installs for your user only - no administrator rights needed.

The Windows installer is not code-signed yet. Windows SmartScreen will warn "Windows protected your PC". To continue, click More info, then Run anyway. Only do this if you accept the risk of running an unsigned app.
