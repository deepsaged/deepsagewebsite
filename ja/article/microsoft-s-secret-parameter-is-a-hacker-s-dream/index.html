マイクロソフトの「秘密の」パラメーターは、ハッカーにとっては夢のようなものだ。

Microsoft Copilotに隠されていたあるデータが、単純なクリック操作をパスワードを盗み出すための貴重な手段へと変えてしまった。

deepsage.com/s/fn9b2l

コードに潜む「うっかり」

ゼロ。それが、ハッカーがMicrosoft Copilotの重大な不備を悪用するために費やした追加の労力である。AIを、気候変動の解決のためにシリコンの雲から降りてくる、超知的なデジタル神と考えることが多いが、実際には、それは単に、あなたの認証情報を漏洩させるための非常に高価な手段に過ぎない場合もある。

最近の研究者たちは、Copilotのエコシステム内に存在する特定の隠されたパラメータが、まるでプライベートなパーティーに招かれざる客のように振る舞い、皆のIDカードを運び回していることを発見した。特定の種類の悪意のあるリンクをクリックすると、システムはあなたの機密情報を何の苦労もなく提供してしまう。巨大なテクノロジー企業でさえ、正面のドアベルを磨くことに夢中で、裏口に鍵をかけ忘れてしまうことがあるようだ。

「秘密のソース」が台無しになるまで

では、これは実際にはどのように機能するのだろうか？クラブにいて、用心棒が「VIP」の特別なリストを持っており、それはどこにも印刷されていないと想像してみよう。そして、そのリストが実際には、誰でも見えるように、皆の首の後ろに貼り付けられていると想像してみよう。この秘密のパラメータは、本質的にそれを行っていた。

ユーザーが特定のリンクをクリックすると、システムはその隠されたデータを含める。これは、AIがコンテキストを理解したり、セッションの継続性を維持したりするのに役立つように設計されたものだが、攻撃者が認証情報の窃取攻撃を容易にする手段となった。一見無害に見えるリンクを作成することで、ハッカーはシステムを欺き、アカウントを乗っ取るために必要なトークンを明らかにさせることができる。

ハッカーが、複雑なサイバーセキュリティのバイパスツールを構築したり、「マトリックス」のようなハッキングシーケンスを実行したりする必要はなかった。彼らは、ソフトウェアがすでにどのように動作しているかを悪用するだけでよかった。それは、「オーシャンズ・イレブン」というよりも、「雷雨の際に玄関のドアに鍵をかけ忘れた」に近い。

脆弱性

Microsoft Copilotの隠されたパラメータにより、攻撃者が悪意のあるリンクを通じてユーザーの認証情報を盗むことが可能になった。

あなたの「素早いクリック」がリスクとなる理由

これは、シリコンバレーのIT部門にとってだけの抽象的な問題ではなく、これらのツールを仕事で利用するすべての人にとっての問題である。最新のクラウドベースの生産性スイートの優れた点は、それがどこにでもあるということだ。それは、あなたのブラウザ、メール、Slackにある。つまり、この脆弱性はあなたのワークフローに付随するということだ。

危険性の内訳は以下のとおりである。

  • 安全の錯覚： Microsoft 365のような「信頼できる」環境にいるため、あなたの脳の「危険」アラームは沈黙したままになる。
  • クリックの罠： リンクは、標準的なドキュメント共有や役立つAIの要約のように見えるかもしれないが、実際には、エクスプロイトを提供するための手段である。
  • 自動化された悪用： ハッカーがパラメータを入手すると、何千人ものユーザーからデータを収集するプロセスを自動化することができる。

現実の確認

今すぐ、ノートパソコンを湖に投げ込む必要はない。Microsoftは一般的に言って、最初に問題を発生させるよりも、問題を修正することの方が得意である。彼らは問題を認識しており、修正パッチに取り組んでいる。しかし、これを教訓として覚えておこう。AIの「魔法」は、旧式の、誤りのあるコードの上に構築されている。

私たちは、これらのモデルが私たちのメールを作成し、会議を要約し、次の大きなビジネスの動きを提案してくれる時代に生きている。しかし、このエクスプロイトが示すように、基盤となるシステムは依然として漏れやすい状態にある。

したがって、次回、Copilotのチャットが、予期しないソースから「自分の身元を確認する」または「共有リソースを表示する」ためにリンクをクリックするように提案してきたら、少し時間を取って考えてみよう。それは役に立つAIなのか、それとも単に、あなたの鍵を渡すための非常に洗練された方法なのか？
