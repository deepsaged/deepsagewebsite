원 클릭, 열 번의 여정

화면에서 서버로, 그리고 다시 화면으로 돌아오는 과정을 단일 버튼 클릭으로 완료합니다

개발 중

개요

웹사이트에서 버튼을 클릭하면, 아주 작은 메시지가 거대한 여정을 시작합니다. 이 책은 그 메시지를 주인공으로 삼아 브라우저를 거쳐 네트워크를 지나 서버에 도달하고, 데이터베이스를 거쳐 다시 돌아오는 과정을 추적합니다. 각 단계에서 만나는 다양한 기술들을 살펴볼 수 있습니다. 이 책은 풀 스택 기술에 대한 가장 명확하고 포괄적인 안내서가 될 것입니다.

배우게 될 핵심 개념

  • 프론트엔드: HTML, CSS, JavaScript
  • HTTP와 API
  • 백엔드 서버
  • 데이터베이스
  • 모든 구성 요소를 쌓아서 조립합니다
