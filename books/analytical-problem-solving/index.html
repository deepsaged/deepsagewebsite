Overview

Big problems look impossible because we see them as one giant knot. Untangle follows an engineer, a chef and a city planner as each faces a crisis that seems hopeless, and shows how they pull the knot apart: define the real problem, split it into pieces, test assumptions, and find the root cause instead of the loudest symptom.

Key concepts covered

  • Defining the real problem
  • Decomposition and issue trees
  • Root cause analysis
  • Hypothesis-driven work
  • Prioritizing by impact
